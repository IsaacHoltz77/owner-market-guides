# owner-market-guides

Quarterly multifamily market intelligence guides by Kansas City submarket, published by Isaac Holtz, Clemons Real Estate.

- `index.html`: landing page listing the submarkets
- `<submarket>/index.html`: one self-contained guide per submarket (Market Intelligence tab; owner comps tab to come)

Each guide keeps all of its figures in one JSON block (`<script id="guide-data">`), so a quarterly refresh means replacing that block.
